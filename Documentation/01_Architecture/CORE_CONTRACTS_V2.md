# Core Contracts v2

Core — независимое доменное ядро MIR Preventive.

## Dependency Direction

```text
UI / Station / Integrations
          ↓
Application / Orchestration
          ↓
       Core Domain
```

Core не зависит от UI, LLM, конкретной БД, сети или сенсора.

## Immutable observations

Принятое исходное измерение не переписывается. Исправление создаёт новую версию или новое событие с явной связью с исходным объектом.

## Unknown ≠ Zero

Отсутствие данных не кодируется числом `0`.

## Provenance

Производные результаты связываются с исходными наблюдениями, источником, временем и версией алгоритма.

## Deterministic boundary

Критические проверки выполняются детерминированными компонентами. AI находится за явным интерфейсом и не может менять исходные измерения.

## Clinical boundary

Core не утверждает наличие заболеваний и не содержит назначения лекарств. Клинические алгоритмы подключаются отдельными валидируемыми модулями.
