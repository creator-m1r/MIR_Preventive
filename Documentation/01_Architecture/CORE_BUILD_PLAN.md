# Core Build Plan

Следующая инженерная итерация после доменного фундамента:

- Swift Package для Core;
- protocol-based repositories;
- DiagnosticSource protocol;
- PersonalBaseline service;
- deterministic TrendEngine;
- RiskEngine protocol;
- PreventiveWorkflow protocol;
- AISupervisor protocol;
- integration tests;
- CI build and test pipeline.

До появления валидированных медицинских моделей Core остаётся клинически нейтральным.
