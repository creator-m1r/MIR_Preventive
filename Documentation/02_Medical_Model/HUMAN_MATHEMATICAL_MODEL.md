# Динамическая математическая модель организма

## 1. Назначение

Human Mathematical Model (HMM) — вычислительная модель для представления наблюдаемых характеристик человека во времени.

Она предназначена для анализа динамики, а не для создания иллюзии полного цифрового двойника организма.

## 2. Состояние

Пусть в момент времени `t` система располагает вектором наблюдаемых и производных параметров:

`X(t) = [x₁(t), x₂(t), ..., xₙ(t)]ᵀ`

Каждый компонент должен иметь описание источника, единицу измерения, качество и метод получения.

## 3. Динамика

Для последовательности наблюдений система может оценивать:

`ΔX = X(t₂) - X(t₁)`

и, при наличии достаточной временной плотности:

`dX/dt ≈ (X(t₂)-X(t₁))/(t₂-t₁)`

Производные не должны рассчитываться при недостаточном качестве или неподходящей временной структуре данных.

## 4. Индивидуальный baseline

Для человека формируется персональная базовая линия `B(t)` или набор устойчивых статистических характеристик.

Отклонение рассматривается как:

`D(t) = X(t) - B(t)`

Конкретная статистическая модель выбирается отдельно для каждого класса показателей и должна проходить валидацию.

## 5. Неизвестные состояния

Отсутствие наблюдения означает `UNKNOWN`, а не ноль.

Нельзя автоматически подставлять среднее значение популяции, если это способно изменить смысл медицинского вывода. Любая импутация должна быть явной и иметь собственный provenance.

## 6. Качество

Каждый параметр сопровождается оценкой качества:

```text
VALID
LOW_QUALITY
REPEAT_REQUIRED
MISSING
INVALID
```

Модель должна учитывать Quality State при любом производном вычислении.

## 7. Многослойность

Модель разделяется минимум на:

1. `Observed Layer` — непосредственно наблюдаемые данные;
2. `Derived Layer` — математически вычисленные характеристики;
3. `Trend Layer` — временные тенденции;
4. `Risk Layer` — риск-сигналы;
5. `Recommendation Layer` — профилактические действия.

Слои не должны смешиваться.

## 8. Версионирование

Каждая математическая модель имеет `ModelVersion`. Изменение формулы, признаков, весов, preprocessing или правил интерпретации создаёт новую версию.

## 9. Принцип научной честности

Модель может быть сложной, но сложность не является доказательством медицинской достоверности. Любая клинически значимая модель требует соответствующей разработки, проверки, валидации и контроля применения.

## 10. Будущее развитие

Архитектура должна позволять подключать модели физиологических систем, органов и процессов только тогда, когда для них существует достаточная доказательная база и понятная область применимости.
