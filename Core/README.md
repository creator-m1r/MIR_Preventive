# MIR Preventive Core

Независимое доменное ядро платформы.

Компоненты этой итерации:

- Domain — типизированные сущности;
- EventBus — доменные события;
- Provenance — происхождение результатов;
- Audit — журнал действий;
- Safety — детерминированная проверка границ.

Core не зависит от UI, LLM, сети, конкретной БД или сенсора.
