# MIR Preventive Core

`Core` — независимое доменное ядро платформы.

## Первые компоненты

- `Domain/CoreDomain.swift` — базовые типы наблюдений, качества, трендов, риск-сигналов, рекомендаций, маршрутов, согласий и аудита.
- `EventBus/EventBus.swift` — actor-based шина доменных событий.
- `Provenance/Provenance.swift` — происхождение вычислительных результатов.
- `Audit/AuditLog.swift` — аудит действий.
- `Safety/SafetyGate.swift` — минимальный deterministic safety gate.

## Архитектурное правило

Core не должен зависеть от UI, конкретной камеры, LLM, базы данных или конкретного медицинского провайдера.

Зависимости направляются внутрь доменной модели через протоколы и явные контракты.

## Ограничение текущей реализации

Текущий `SafetyGate` является инженерным фундаментом, а не клиническим алгоритмом. Он не содержит медицинских порогов и не должен использоваться как медицинское устройство или диагностический механизм без дальнейшей разработки и валидации.
