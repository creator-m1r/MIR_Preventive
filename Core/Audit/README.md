# Audit

Audit Log фиксирует ключевые действия и изменения системы.

Минимальный аудит содержит тип события, timestamp, actor, связанный объект и дополнительные метаданные.

Аудит не является медицинской историей сам по себе; он предназначен для технической воспроизводимости, безопасности и расследования событий.
