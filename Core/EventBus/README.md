# Event Bus

Actor-based доменная шина событий.

События используются для слабой связанности между сбором измерений, BioModel, Risk Engine, Preventive Engine, AI Supervisor и аудитом.

Событие должно иметь уникальный идентификатор, время возникновения и тип. Обработчики не должны изменять исходное событие.
